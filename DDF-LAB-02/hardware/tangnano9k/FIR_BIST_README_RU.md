# DDF-LAB-02: аппаратная самопроверка FIR N=4 на Tang Nano 9K

**Назначение:** проверить не просто мигание LED, а прохождение фиксированного набора реальных цифровых отсчётов через исходный `rtl/moving_average4.v`, синтезированный и реализованный в GW1NR-9C.

**Что не меняем:** `rtl/moving_average4.v`, уже завершённый тестбенч LAB-02, действующий проект мигающего LED, документацию v0.1.

## Схема

- 27 МГц, pin 52; кнопка сброса (активна при 0), pin 3.
- LED на pin 10: **PASS**, загорается постоянно после успешного контроля 20 векторов.
- LED на pin 11: **FAIL**, загорается постоянно при любом обнаруженном расхождении.
- LED на pin 13: **heartbeat**, переключается примерно раз в 0,5 с и подтверждает работающий тактовый домен.

Все LED активны по низкому уровню. При сбросе оба индикатора результата погашены; heartbeat остановлен.

## Почему проверка независима от ядра

Для каждого такта имеются захардкоженные контрольные значения, рассчитанные заранее, а не прочитанные из внутренних регистров DUT. Проверяются `data_out` и `valid_out` после установленной задержки наблюдения в один такт. Содержимое невалидных входов игнорируется, выход при `valid_in=0` удерживает значение. Испытываются импульс, нули, пропуски, полный диапазон 4095 и переходы, в которых значимо округление вниз.

**Ограничение:** набор фиксированный, не исчерпывает все комбинации. Для итоговой лабораторной потребуется внешний обмен по UART и сопоставление независимой модели с фактически полученными от FPGA данными.

## 1. Проверка самопроверяющегося стенда симулятором

Из `C:\GitHub\DDF\DDF-LAB-02` запустить:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\hardware\tangnano9k\test_fir_bist.ps1
```

Ожидаемые маркеры — `BIST_SIM_PASS`, `BIST_MUTATION_DETECTED`, `DDF_FIR_BIST_SIM_AND_MUTATION_PASS`. Сам отрицательный тест использует существующий `rtl_mutant` (намеренно неверное деление на 8).

## 2. Gowin Education V1.9.9Beta-4

После успешных программных тестов:

```powershell
$gw = 'C:\Gowin\Gowin_V1.9.9Beta-4_Education\IDE\bin\gw_sh.exe'
& $gw .\hardware\tangnano9k\build_fir_bist.tcl
Write-Host "Exit: $LASTEXITCODE"
```

Ожидаемый артефакт: `hardware/tangnano9k/build/fir_bist/impl/pnr/fir_bist9k.fs`.

## 3. Физическая загрузка

Только после успешной проверки .fs загружается исключительно **SRAM**, не Flash, тем же проверенным Gowin Programmer CLI с `--operation_index 2`.

Обязательно записать фактическое наблюдение: LED PASS включился? LED FAIL выключен? LED heartbeat мигает? На кнопку сброса индикаторы результата реагируют?

## Достоверность и пределы утверждений

Этот комплект содержит исходники. Его аппаратная работоспособность считается `NOT RUN`, пока на физической плате не пройдены шаги 1–3 и не получен реальный протокол наблюдения. Предыдущий LED test доказывает только программирование и тактирование платы, а не FIR.
