# DDF — Digital Design Flow

Маршрут проектирования цифровых устройств.
Digital Design Flow — Digital Hardware Design Course.

## Laboratory works / Лабораторные работы

### DDF-LAB-01
Исследование сигналов, численной точности
и выбор архитектуры цифрового устройства.

Signal analysis, fixed-point precision
and architecture exploration.

### DDF-LAB-02
Проектирование и проверка цифрового
FIR-фильтра (скользящее среднее, N=4).

RTL design and verification of a
4-tap moving-average FIR filter.

## Repository policy

- One repository for the entire course.
- Each laboratory has its own directory.
- Source code and verification scripts are retained.
- Reproducible experimental results are retained.
- Documentation is maintained in Russian and English.
- Temporary build artifacts are excluded.
